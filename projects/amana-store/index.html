FRONTEND PROJECT

Amana Store

A clean, modern admin dashboard with analytics, revenue tracking and activity monitoring, built with React, TypeScript, Tailwind CSS and Next.js.

Live Demo

Technologies Used

React TypeScript Tailwind Next.js

Overview

Amana Store is an e-commerce storefront that brings analytics, revenue tracking and activity monitoring into a single, readable workspace. The whole layout is organised around clarity: the most important numbers are visible first, details follow.

About the project

The storefront is designed around easy product discovery, clear categories, product presentation and a simple shopping cart experience.

Main features

The storefront is assembled from reusable commerce building blocks.

  • Product listings with imagery and pricing
  • Category-based browsing
  • Shopping cart with item management
  • Reusable product card components
  • Clean, family-friendly storefront presentation

Technologies used

Next.js and React power the storefront and its navigation, TypeScript types the product and cart models, and Tailwind CSS keeps the visual system consistent across every page.

Design / UI approach

The layout keeps a calm, uncluttered rhythm: a consistent product grid, clear typographic hierarchy for names and prices, and restrained accents reserved for actions such as adding to the cart.

Implementation details

Products and categories are modelled as typed data and rendered through shared components, while cart state is handled in one place so quantity changes and totals stay predictable across the app.

Responsive behavior

The product grid adapts column count by breakpoint, navigation collapses into a mobile-friendly menu, and cart controls stay large enough to use comfortably on touch devices.

Purpose

Amana Store demonstrates the ability to structure a real e-commerce interface with reusable components, a coherent design system and a user-friendly shopping experience.
